# Changelog

## 1.0.0
- Обробка записів про доставлення посилок (варіант 15)
- Maven Wrapper, JUnit 5, SpotBugs, виконуваний JAR
- GitHub Actions на Ubuntu, Windows, macOS
- Відхилення NaN та Infinity у weightKg

## 2.0.0

- Реалізовано незмінну модель Parcel.
- Додано централізовану валідацію даних.
- Реалізовано метод Parcel.fromCsv().
- Додано record WeightDelivery.
- Реалізовано Parcel.Builder.
- Проведено рефакторинг зі збереженням результатів Lab 1.
- Розширено набір автоматизованих тестів до 50.
- SpotBugs не виявив дефектів.
- Успішно перевірено збірку на Ubuntu, Windows та macOS.
- Оновлено README.md та REPORT.md.

## 3.0.0

- Реалізовано успадкування та поліморфізм класів Parcel, RegularParcel та ExpressParcel.
- Додано enum DeliveryKind.
- Реалізовано методи обчислення вартості та терміну доставлення.
- Реалізовано equals() та hashCode().
- Додано sealed-ієрархію та вичерпний switch.
- Реалізовано клас ParcelTypeResolver.
- Розширено набір автоматизованих тестів до 79.
- Успішно перевірено збірку на Ubuntu, Windows та macOS.
- Оновлено README.md та REPORT.md.

## 4.0.0

- Реалізовано обробку колекції посилок за допомогою Java Stream API.
- Додано клас ParcelQueries.
- Розширено предметну модель габаритами та статусом доставлення.
- Додано enum ParcelStatus.
- Реалізовано фільтрацію посилок за статусом та формування списку міст.
- Реалізовано групування посилок за містом із визначенням їх кількості.
- Додано обчислення статистичних показників ваги через DoubleSummaryStatistics.
- Реалізовано top-N посилок за вагою та номером.
- Реалізовано пошук посилки за номером через Optional.
- Інтегровано запити Stream API до класу ParcelReport.
- Реалізовано дворівневе групування за статусом та містом доставлення.
- Додано перевірку відсутності мутації вхідної колекції.
- Збережено контрольні показники попередньої лабораторної роботи.
- Розширено набір автоматизованих тестів із 79 до 101.
- Успішно виконано локальну збірку та перевірку SpotBugs.
- Налаштовано автоматичне визначення версії проєкту.
- Оновлено README.md та REPORT.md.
- Успішно перевірено збірку на Ubuntu, Windows та macOS.
- Опубліковано три JAR-артефакти через GitHub Actions CI #64.
