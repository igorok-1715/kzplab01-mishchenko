## 2. Мета роботи
Пройти шлях від створення репозиторію до консольної програми, яку можна
відтворено зібрати й запустити на Windows, macOS та Ubuntu.

## 3. Постановка задачі
Формат запису: `id:String; weightKg:double; city:String; deliveryDays:int; express:boolean`.
Показники: кількість коректних записів, середня вага, найбільший термін, кількість експрес-доставлень.

## 4. Структура програми
`Main` (аргументи) → `FileReport.readLines` → `ParcelReport.buildReport`
(перевірка → перетворення → обчислення → текст) → консоль і `FileReport.writeReport`.

## 5. Інфраструктура
Рівень 1: лише код і документація.
Рівень 2: `pom.xml` (JUnit 5, SpotBugs у фазі verify, maven-shade-plugin), Maven Wrapper.
Рівень 3: GitHub Actions (`.github/workflows/ci.yml`), матриця трьох ОС, артефакт JAR.
